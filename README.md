This project tackles the inherent challenges of using UDP 
as a transport layer protocol throught the recreation of
the game turned based game Pokemon Showdown. It is a socket 
program that sends messages between a client and a server 
such as the data of the opponent pokemon, the moved used
by the opponent, and stickers sent by either player. This
program also allows non players to view the ongoing battle
as spectators through the use of UDP's broadcast feature.
